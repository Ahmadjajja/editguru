## One product experience

**Target default:** Idea → Generate → Watch → Describe a change. FRAME writes the narrative and directs the video. Exact script, voice, format, and detailed direction belong under optional controls. Paid Fish narration requires a credit quote and explicit confirmation before synthesis.

**Current technical pilot:** Idea + exact script → directed preview narration → semantic portrait graphics → playable first cut → visual revision → saved versions and MP4 download. The public route accepts an explicitly labeled Edge preview narrator. It limits scripts to 80 words and 1,800 characters, approximately one minute, and 720×1280 portrait output. It uses typography and vector diagrams; it does not accept footage in this route. Each invite owns its own project list, project reads/actions, and media links. Its mandatory script is a known gap against the target default.

The first page opens directly to Idea, Script, and Generate. The pilot gateway hides the extra voice selector and prevents Fish credit actions, saved-demo import, Advanced Studio, and the footage editor. Each invitation permits two projects, with two visual revisions and one retry per project. Those other tools remain in source for later evaluation and are not claims of this public experience.
