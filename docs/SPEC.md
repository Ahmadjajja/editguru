# FRAME product contract

The creator directs an editing agent from an iPhone. The agent uses actual media tools to make and explain edits. Every phase creates a separate playable, persistent MP4 checkpoint: (1) Story & Rhythm, (2) Studio & Visuals, (3) B-roll & Storytelling, (4) Captions & Graphics, (5) Sound & Final Polish.

At each phase the creator can direct, watch, revise, continue, restore an earlier checkpoint, and export. The app must persist projects and recovery state across interruption. Creative rationales and user feedback are recorded without claiming a preference model exists.

Acceptance requires real sample footage, verified transformation between checkpoints, playable output with synchronized audio, no clipped speech, revision and restore behavior, interrupted-upload recovery, valid MP4 export, and iPhone usability. Subjective creative quality is assessed separately from technical validity.
